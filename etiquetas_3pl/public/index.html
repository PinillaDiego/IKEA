¿No aparecen impresoras?
  1. Instale Zebra Browser Print en este PC y verifique que esté abierto (ícono en la bandeja).
  2. Agregue la impresora en Browser Print (USB o red) y márquela como predeterminada.
  3. Abra https://127.0.0.1:9101/ssl_support y acepte el certificado una vez.
  4. Cuando el navegador o Browser Print pregunten si permiten este sitio / acceso a la red local, acepte.
